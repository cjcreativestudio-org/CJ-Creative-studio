# 09 — We Redesigned Our Own Site (Before/After)

**Pillar:** P2 Before/After · **Length:** ~30s · **Audience:** both (design-aware skew)
**Assets:** cjcreativestudio.com (new editorial design), the old design (check out a pre-redesign commit locally, or use an old Vercel preview deployment), git history

## Hook (first 1.5s)

**Spoken + on-screen:**
> "We redesigned our own website and honestly, the before hurts. Watch."

Visual: the OLD homepage, held for one beat.

## Voiceover

> "We redesigned our own website and honestly, the before hurts. Watch.
> The old site was… fine. Clever effects, but it looked like every other dev portfolio.
> Fine doesn't win clients.
> The new one has a point of view. Editorial layout. Type that takes up space. Sections that breathe.
> Same content. Same company. Completely different first impression.
> If we'd send it to a client, we have to be willing to wear it ourselves. Now we are."

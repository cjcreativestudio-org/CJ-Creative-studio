## Voiceover

> "I built an AI chief of staff that runs my web agency. This is its dashboard.
> Every task on this board is a job for an agent — client site changes, research, content, code review.
> I talk to each project's agent like a colleague. It works in that project's actual repo.
> They build in isolated branches, test their own work, and report back.
> Every project gets its own agent. I just point them.
> This is what a one-person agency looks like in 2026."
